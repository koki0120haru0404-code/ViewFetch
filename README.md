# ViewFetch
neofetchのシンプルな代替ツール 

古いLinux、Bash 1.0で動作する軽量な構成確認ツールです。 

サイズは3KBで超軽量。基本的な情報を確認できます。 


## 推奨スペック(保証しません)
CPU:1.5GHz+2C/2T以上 

RAM:512MB以上 

Bash:3.0以上 


## 最低スペック(保証しません。)
CPU:1.0GHZ+1C/1T 

RAM:256MB 

Bash:1.0 

## インストール方法

1:[sudo apt install make]を実行。

2:ファイルがある階層に移動して[make build]を実行。

3:[./viewfetch]を実行
